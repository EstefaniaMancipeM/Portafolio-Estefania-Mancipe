Mis pendientesJavaScript + almacenamiento local

LÓGICA EN EL NAVEGADOR

Mis pendientes

Una agenda para registrar tareas con nombre, descripción y fecha, marcarlas como terminadas y eliminarlas de la lista.

Cómo está construido
La clase TaskManager organiza las tareas y separa su gestión de los eventos del formulario. La aplicación valida campos y guarda la colección en localStorage.
Qué demuestra
Manejo del DOM, objetos, identificadores y eventos delegados. El historial muestra la evolución desde tarjetas estáticas hasta una lista gestionada con JavaScript.

MODELADO CON JAVA / 03

Clínica veterinariaUn modelo común. Comportamientos distintos.

PROGRAMACIÓN ORIENTADA A OBJETOS

Clínica veterinaria

Un ejercicio de consola que representa distintas especies, calcula sus consultas y organiza comportamientos de vacunación y seguro.

Cómo está construido
El modelo parte de Animal, una clase abstracta, y utiliza especializaciones e interfaces como Vacunable y Asegurable para expresar responsabilidades distintas.
Qué demuestra
Abstracción, herencia, interfaces y polimorfismo con Java. Es un ejercicio de fundamentos, sin API ni base de datos conectada.
